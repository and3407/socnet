Добавил в проект кеширования постов друзей пользователей. 
Кеширование настроил через redis. redis запускается в отдельном сервисе.
Также добавил redis_commander, для просмотра содержания redis.
Время жизни кеша 5 минут.

Для хранения постов добавил несколько таблиц.
- posts - хранит контент поста и автора
- user_friends - соотношения пользователей и друзей пользователей

Добавил апи метод для получения постов пользователей. При запросе посты берутся из кеша.
Если нет кеша, то кеш создается и возвращается из кеша.
- постман коллекция social_network.postman_collection.json

Запуск проекта.

1. Выполнить сборку образов и запустить контейнеры.
````
docker-compose up --build -d
````

2. Войти в контейнер php. Выполнить миграцю схемы.
````
docker-compose exec php bash

php migrate.php
````

Заполнить users
```` 
сd app/Database/migrations/upload_users 
php run.php
````

Заполнить posts
```` 
сd app/Database/migrations/upload_posts
php run.php
````

Заполнить user_friends
```` 
сd app/Database/migrations/upload_friends
php run.php
````

- При выполнении команд, должны создаться пользователи, посты и для каждого пользователя заполнятся друзья. 
В итоге при запросе постов, у каждого пользователя, должно быть около 1500 постов. 
В кеше хранятся, 1000 постов самых свежих.
